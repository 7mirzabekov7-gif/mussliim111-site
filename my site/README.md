# напоминание — v1.7

Это финальный визуальный вариант в стиле первой версии: минималистичный тёмный фон, золото, мягкая типографика и минимум декоративных элементов.

## Автоматическая лента Telegram

Сервер получает `channel_post` и `edited_channel_post` через Telegram Bot API и сохраняет последние публикации в `posts.json`. Сайт обновляет ленту раз в 60 секунд.

1. Создай бота через @BotFather.
2. Добавь бота администратором в @mussliim111.
3. Скопируй `.env.example` в `.env`.
4. Вставь токен в `BOT_TOKEN`.
5. Выполни `npm install`.
6. Запусти `npm start`.
7. Открой `http://localhost:3000`.

Если у бота установлен webhook, перед использованием long polling его нужно удалить. Telegram указывает, что `getUpdates` и outgoing webhook взаимно исключают друг друга.

## Фотография

Hero использует реальную фотографию мечети Пророка ночью из Wikimedia Commons, с указанием автора и лицензии в самом сайте.

## Важно

Токен Telegram хранится только в `.env` на сервере и никогда не должен попадать в `public/index.html`.

Для публичного сайта используй HTTPS и постоянный сервер/VPS.
