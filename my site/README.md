# Напоминание — v1.8

Обновлённая мобильная версия сайта для `@mussliim111`.

## Что нового
- аватар канала в шапке;
- мобильная вёрстка без горизонтального переполнения;
- арабская каллиграфия;
- повторяющиеся тексты удаляются автоматически;
- последние публикации публичного Telegram-канала подгружаются автоматически;
- обновление ленты раз в минуту + кнопка ручного обновления;
- сохранён тёмно-золотой стиль.

## Render
Root Directory: `my site`
Build Command: `npm install`
Start Command: `npm start`
Environment Variable: `CHANNEL=@mussliim111`

`BOT_TOKEN` для этой версии не нужен для чтения публичной ленты. Его можно оставить в Render, но сайт его не использует.
